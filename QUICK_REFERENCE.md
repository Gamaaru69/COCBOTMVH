# Quick Reference

## Public Commands
- `/start` - Start the bot
- `/help` - Show help
- `/clan` - Clan information
- `/events` - Current events
- `/war` - Current war status
- `/warstats` - Detailed war statistics
- `/warlog` - Last saved war log
- `/warhistory` - Last 5 saved wars

## Admin Commands
- `/adminhelp` - Show admin commands
- `/warlogupdate` - Save the ended war to history
- `/addwarlogmanually <clan> <opponent> <result> <clan_stars> <opponent_stars> <clan_destruction> <opponent_destruction>`
